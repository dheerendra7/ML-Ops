# Security Policy

This repository is educational material and does not operate a hosted service.

## Reporting
Do not publish credentials, access tokens, private cluster endpoints, or exploitable details in a public issue. Contact the repository maintainer privately through the GitHub profile with the affected file, impact, and safe reproduction details.

## Safe use
- Never commit secrets, kubeconfig files, service-account tokens, private keys, or production data.
- Review RBAC and network access before applying examples.
- Use disposable development environments for experiments.
- Examples do not replace threat modeling or platform-specific security review.

No service-level response-time commitment is implied.
